# GoLang Project 🚀

A simple and powerful GoLang-based web application demonstrating how to build a backend service using Go. This project is designed to help beginners get started with Go web development and serve basic HTML content.

---

## 📁 Project Structure

```
go-ui-demo/
├── main.go           # Entry point of the application
├── README.md         # Project documentation
```

---

## 🛠️ Features

- 🌀 Simple HTTP server in Go  
- 🔥 Serves basic HTML content  
- ⚡ Lightweight and fast performance  
- 💡 Easy to extend with API routes or templates  

---

## 🚀 Getting Started

### ✅ Prerequisites

- Go 1.20 or later installed  
  👉 [Download Go](https://go.dev/dl/)

### 🔧 Run the Project

```bash
# Step into project folder
cd go-ui-demo

# Run the server
go run main.go
```

Visit: [http://localhost:8080](http://localhost:8080) in your browser.

---

## 💻 Example Output

```html
<h1>Hello from Go!</h1>
<p>This is a web UI.</p>
```

---

## 📦 Build Binary (Optional)

To create an executable:

```bash
go build main.go
```

This creates:
- `main.exe` on Windows  
- `main` on Linux/macOS
